Télécommande VibH2O

Installer : dans Safari, bouton Partager → Sur l'écran d'accueil. L'icône ouvre ensuite la télécommande en plein écran.

Adresse : — c'est le PC Unreal. Elle est écrite dans le log Unreal au lancement (telecommande iPad — ouvrir…).

En-tête : MAX (vert) = les capteurs arrivent de Max. SIMULATION (orange clignotant) = de fausses données remplacent Max. AUCUNE DONNÉE (rouge) = rien n'arrive. Puis l'ambiance, le fond, et les zones éteintes.

Attracteurs : un appui appelle les bulles, un second les renvoie à leur place. TOUT RELÂCHER renvoie tout le monde. Double appui sur Durée des fondus : retour à ×1.

Zones : faire glisser une zone sur le tulle pour suivre une circassienne. Pour éteindre une zone, maintenir sa pastille jusqu'au bout de l'anneau ; un simple appui la rallume. Pareil pour passer le fond au noir et couper un effet.

Tableaux : « → Salle » et « → Banc » font glisser la salle d'un tableau à l'autre. Le curseur fin est caché derrière Déverrouiller le curseur.

Dans le noir : ☾ passe en thème de nuit. 🔒 bloque tout ; pour déverrouiller, maintenir 🔒 1,5 s.

Commande non reçue (bandeau rouge) : Unreal n'a pas eu l'ordre ; le bouton revient à l'état réel. Recommencer.

Point vert : Unreal répond. Point rouge : plus de réponse — vérifier le Wi-Fi et que le jeu tourne.
